Welcome

This wizard configures your local Obsidian vault to be reachable by Perplexity (or any MCP client) via Streamable HTTP.

What this wizard does

  1. Asks for the absolute path to your Obsidian vault.
  2. Lets you choose read-only / writable and which tools are exposed.
  3. Generates a strong API token for Perplexity to authenticate with.
  4. Writes config.json in this folder.
  5. Boots the MCP server briefly and verifies the tools list.
  6. Walks you through exposing it over HTTPS for Perplexity (Windows 11).

Pick your Obsidian vault

Paste the absolute path to your vault folder. On Windows it looks like C:\Users\You\Documents\My Vault.

Tip in Windows 11: open the vault folder in File Explorer, click the address bar, and copy the path.

Server & authentication

The MCP server runs on this machine and listens on a local port. Bind to 127.0.0.1 so only your machine (and your tunnel) can reach it.

Keep this as 127.0.0.1 unless you know why you'd change it.
Perplexity will send this as Authorization: Bearer <token>. Required when exposing publicly.

Test & connect

First we'll boot the MCP server briefly to confirm it works, then walk through exposing it over HTTPS so Perplexity can reach it.

1. Smoke test the MCP server

2. Expose to Perplexity over HTTPS

Perplexity needs an HTTPS URL. Pick a tunnel below — this wizard detects what's installed on your machine.

3. Add the connector in Perplexity

Once your tunnel is running and gives you an https://... URL, open Perplexity and:

  1. Go to Settings → Connectors → Add custom connector
  2. Server URL: https://your-tunnel-host/mcp
  3. Transport: Streamable HTTP
  4. Authentication: API Key (Bearer)
